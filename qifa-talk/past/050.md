# 050. 【女性专场】性别、科技职场与移民生活：聊聊我们的经历与困惑

* **时间**：9/13/2026 周日
* **地点**：Bellevue Library
* **类型**：科普/讨论
* **Host**：Jing

{: .note-title }
> **话题简介 (Topic Description)**
>
> 活动前半小时，Jing会结合自己在美国和中国开展的田野调查，分享一些关于华人女性科技从业者及其社群的初步发现。之后会从大家具体的生活和职业经验出发，一起聊聊进入美国科技行业、求职与职业发展、职场中的性别与文化体验，以及签证、移民身份和地缘政治环境如何影响我们的职业选择与未来规划。
> 这会是一个以经验分享和交流为主的活动。大家可以分享自己的经历、困惑和观察，也可以听听处在不同职业阶段和移民阶段的女性如何理解和应对这些问题。
