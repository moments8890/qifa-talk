# 052. 什么样的亲密关系更适合自己？

* **时间**：9/27/2026 周日
* **地点**：Redmond Library
* **类型**：讨论/分享
* **Host**：Ivy

{: .note-title }
> **话题简介 (Topic Description)**
>
> 结婚？不婚？长期伴侣？单身？还是其他关系形式？我真正想从亲密关系中得到什么？什么样的关系更适合我现在的人生阶段、价值观和需要？
> 我们常把人生想象成一条默认路线：单身→恋爱→同居→结婚→一辈子。但亲密关系远不止这一种。有人享受单身，有人dating但不追求长期承诺，有人想要稳定的life partner却不想结婚，也有人重视婚姻本身。除此之外，还有long-distance、living apart together、childfree partnership、open relationship、ENM/poly等不同选择。
> 这一次，我们把这些可能性摆在桌面上聊聊。
> 📝
