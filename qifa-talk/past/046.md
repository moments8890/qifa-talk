# 046. 体验一棵树

* **时间**：8/22/2026 周六
* **地点**：Volunteer Park
* **类型**：科普/讨论
* **Host**：吴凡

{: .note-title }
> **话题简介 (Topic Description)**
>
> 你在街上匆忙行走的时候，你是否留意过头顶的绿色，那些层层叠叠的叶子，是什么形状？当你公园里闲逛的时候，你是否曾经想要知道那些树的名字，它们枝叶伸展的样子、树皮的纹理又有什么不同，甚至是….它们是否有不同的性格？
> 我们会在Volunteeer Park一起聊树、认识树，抚摸和认识树皮的纹理，用拓印和拥抱树的方式理解和体验一棵树。
