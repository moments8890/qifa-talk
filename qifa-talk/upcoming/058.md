# 058. 聊聊《红楼梦》里的人和诗

* **时间**：10/18/2026 周日
* **地点**：Bellevue Library
* **类型**：科普/讨论
* **Host**：书雅

{: .note-title }
> **话题简介 (Topic Description)**
>
> 中秋节刚过，想和喜欢《红楼梦》、或者只是对《红楼梦》有一点好奇的朋友们一起聊聊这本书。红楼梦里的中秋是什么样的？她们赏什么月、作什么诗？那些看似风雅的中秋夜，又藏着怎样的心事？
> 我们也会从中秋说开去，重新看看《红楼梦》里的人：探春的清醒与抱负，王熙凤的精明与恻隐，晴雯的锋利与脆弱，以及宝黛之间的情感……我们会看到怎样复杂、矛盾又鲜活的一生？
> 最后，也想聊一个可能更属于我们自己的问题：为什么身处西雅图的我们，需要读《红楼梦》？
