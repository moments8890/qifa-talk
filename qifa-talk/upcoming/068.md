# 068. 游戏人间

* **时间**：12/19/2026 周六
* **地点**：Verde Estarra Park
* **类型**：科普/讨论
* **Host**：阿朱

{: .note-title }
> **话题简介 (Topic Description)**
>
> 我读master的时候上过一门game design的课，对“游戏”有了全新的理解。除了传统的桌面游戏和电子游戏以外，球类运动、捉迷藏、真心话大冒险、辩论、密室逃脱、积分系统、抢红包也都是游戏。本期讨论局会介绍游戏的定义和游戏设计，然后一起讨论生活中的哪些活动（升职/谈恋爱/社交）也属于游戏，以及你想怎么玩地球online。
